# Transformer 迁移元数据说明

本目录存放从 `transformer_my` 向 `transformer` 单目录正式工作区迁移时保留下来的历史 filelist、旧清单和阶段性元数据。

## 放入本目录的原则

1. 文件用于记录迁移前的工作区结构和来源资产，不作为正式编译输入。
2. 文件允许继续作为追溯、交接和论文说明材料使用。
3. 文件中的旧路径可能仍保留 `transformer_my`，但这些路径都只具备历史意义。
